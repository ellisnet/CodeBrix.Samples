THIRD-PARTY NOTICES
===================

This file documents third-party content that is bundled with, or used at run
time by, the DRAKON.Brix sample application, together with the licenses under
which that content is provided.

Third-party CODE dependencies are consumed as NuGet packages. Each package
carries its own license and third-party notices in its own repository/package
(the CodeBrix.* packages ship their own THIRD-PARTY-NOTICES.txt), so those are
not reproduced here. That includes the Tcl/Tk and Eagle heritage of the managed
Tcl interpreter, the Tk toolkit and the sqlite3 and pdf4tcl command shims this
application runs on, all of which arrive inside the CodeBrix.Platform.TclTk,
CodeBrix.Platform.TclTk.Extras and CodeBrix.Platform.TkCanvas packages and are
covered by the notices those packages ship.

DRAKON Editor (bundled)
------------------------------------------------------------------------
Project:   DRAKON Editor 1.33
Author(s): Stepan Mitkin and contributors
Source:    https://github.com/stepan-mitkin/drakon_editor
License:   PUBLIC DOMAIN, per the upstream readme.html: "DRAKON Editor is
           PUBLIC DOMAIN except some third-party components (pdf4tcl,
           Liberation fonts)."

DRAKON Editor material bundled in this folder:

  * src/DRAKON.Brix.Core/Assets/drakon/ - the complete DRAKON Editor 1.33
    program tree (its Tcl source, generators, images, message catalogs and
    scripts), vendored UNMODIFIED and copied beside the binaries at build
    time so the application can source it. See the PROVENANCE.txt file in
    that directory. The two excepted third-party components carried along
    inside it - fonts/ and pdf4tcl07/pkgIndex.tcl - are covered by their own
    sections below.
  * examples/ - DRAKON Editor's own example diagrams (.drn) and the generated
    source, build scripts and compiled artifacts that ship beside them, per
    target language.
  * docs/ - DRAKON Editor's own documentation: the DRAKON language book, the
    per-language generator guides, and the .drn file-format description.
  * art/ - DRAKON Editor's icon source artwork.

The application's own bootstrap script, src/DRAKON.Brix.Core/Assets/
bootstrap.tcl, is not DRAKON Editor material: it is a new file written for
this application, and its header says so.
