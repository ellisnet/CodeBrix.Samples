This file documents third-party content that is bundled with, or used at run
time by, the GameEngineMusicDemo sample application, together with the licenses
under which that content is provided.

Third-party CODE dependencies are consumed as NuGet packages. Each package
carries its own license and third-party notices in its own repository/package

not reproduced here. That includes the game engine package, which supplies the

------------------------------------------------------------------------
Audio assets (written at run time, not bundled)
------------------------------------------------------------------------
Every asset this application plays is generated by the application itself, by
  src/libs/GameEngineMusicDemo.Game/MusicAssetFactory.cs
on first run, into a "GeneratedMusic" folder beside the executable. The layers,
the two linear tracks, the stinger, the dialogue blip, the instrument tone, the
bell sample, the two MIDI files and the whole stems export are all computed
arithmetically in that one file. None of them contains recorded, sampled,
performed or otherwise third-party material, and all of them are covered by this
repository's own license (see LICENSE at the repository root).

The files are written in three open, publicly documented formats, and using a
format is not the use of anyone's content:

  - RIFF/WAVE (.wav) audio and Standard MIDI File (.mid) - long-standing open
    interchange formats.

  - SFZ (.sfz) - an open, plain-text sampler-instrument format. The instrument
    written here is one generated region pointing at a generated tone; no SFZ
    instrument, sample set or library from any third party is used.

  - Decent Sampler preset (.dspreset) - a plain-text XML instrument format read
    by the Decent Sampler instrument player from Decent Samples. The preset
    written here is authored from scratch by the asset factory and points only
    at a sample the same code generated; no Decent Sampler instrument, sample
    library or other content from Decent Samples or from any third-party
    instrument author is used or redistributed. "Decent Sampler" and "Decent
    Samples" are the property of their respective owners and are named here only
    to identify the file format.
