THIRD-PARTY NOTICES
===================

This file documents third-party content that is bundled with, or used at run
time by, the PdfSideBySide sample application, together with the licenses
under which that content is provided.

Third-party CODE dependencies are consumed as NuGet packages. Each package
carries its own license and third-party notices in its own repository/package
(the CodeBrix.* packages ship their own THIRD-PARTY-NOTICES.txt), so those are
not reproduced here. That includes the PDF rasterizer library and the PDFium
natives it bundles.

------------------------------------------------------------------------
Android head  (src/PdfSideBySide.Android)
------------------------------------------------------------------------
The Android head contains no third-party files of its own. Its build brings
in, as NuGet packages, the following third-party code that ends up inside the
Android application package:

  - Material Components for Android and the AndroidX libraries (Google), in
    their .NET bindings (Xamarin.Google.Android.Material, Xamarin.AndroidX.*),
    licensed under the Apache License, Version 2.0. They arrive through the
    CodeBrix.Android package, which draws every control with them.

  - The PDFium native libraries for android-arm64 and android-x64, which the
    PDF rasterizer package redistributes beside its desktop ones (see above).

Each of those packages carries its own license and notices, and the
CodeBrix.Android packages ship their own THIRD-PARTY-NOTICES.txt; they are
not reproduced here.

------------------------------------------------------------------------
Test fixture: Inanna.pdf
  (bundled: tests/libs/PdfSideBySide.PdfRender.Tests/assets/Inanna.pdf)
------------------------------------------------------------------------
The rendering tests open a fixed PDF so page counts and rendered pages can be
asserted. The fixture is the Wikipedia article "Inanna" (Ancient Mesopotamian
goddess), by Wikipedia contributors, rendered to PDF by the CodeBrix document
stack. It is used only by the test project and is not part of the
application.

Wikipedia article text is licensed under the Creative Commons
Attribution-ShareAlike license (CC BY-SA;
https://creativecommons.org/licenses/by-sa/4.0/). Article images carry their
own individual licenses, as noted on their Wikimedia description pages.

------------------------------------------------------------------------
User documents (opened at run time)
------------------------------------------------------------------------
The application opens and displays PDF files the user selects. The rights to
that content remain with its owners; nothing else is redistributed as part of
this repository.
