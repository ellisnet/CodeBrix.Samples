THIRD-PARTY NOTICES
===================

This file documents third-party content that is bundled with, or used at run
time by, the PdfSideBySide sample application, together with the licenses
under which that content is provided.

Third-party CODE dependencies are consumed as NuGet packages. Each package
carries its own license and third-party notices in its own repository/package
(the CodeBrix.* packages ship their own THIRD-PARTY-NOTICES.txt), so those are
not reproduced here. That includes the PDF rasterizer library and the PDFium

------------------------------------------------------------------------
Test fixture: Inanna.pdf
  (bundled: tests/libs/PdfSideBySide.PdfRender.Tests/assets/Inanna.pdf)
------------------------------------------------------------------------
The rendering tests open a fixed PDF so page counts and rendered pages can be
asserted. The fixture is the Wikipedia article "Inanna" (Ancient Mesopotamian
goddess), by Wikipedia contributors, rendered to PDF by the CodeBrix document
stack. It is used only by the test project and is not part of the
application.
