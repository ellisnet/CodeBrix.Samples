THIRD-PARTY NOTICES
===================

This file documents third-party content that is bundled with, or used at run
time by, the SimpleCbxVideoPlayer sample application, together with the licenses
under which that content is provided.

Third-party CODE dependencies are consumed as NuGet packages. Each package
carries its own license and third-party notices in its own repository/package
(the CodeBrix.* packages ship their own THIRD-PARTY-NOTICES.txt), so those are
not reproduced here. That includes the AV1 video decoder and the Opus audio
decoder this application registers at start-up, and the Skia bindings and native
Skia binaries the drawing surfaces are built on.

------------------------------------------------------------------------
Video corpus (bundled: src/SimpleCbxVideoPlayer.Core/Assets/authoring/**)
------------------------------------------------------------------------
The clips under Assets/authoring/ - the MKV/, WebM/, CodeBrix-Mode1/ and
CodeBrix-Mode2/ folders - are AV1 video with Opus or Vorbis sound, derived by
re-encoding two phone recordings.

Those two recordings were created by Jeremy Ellis and placed by him in the
PUBLIC DOMAIN on 2026-08-29. That dedication covers everything derived from
them, so every file in all four folders is Public Domain as well. No rights are
reserved, no attribution is required, and no license obligation attaches to any
of them.

Nothing in that folder is third-party media. The two original recordings
themselves are not bundled here.

Assets/authoring/README.txt and Assets/authoring/MANIFEST.txt carry the full
record: the dedication above, what each file is, and the exact encoder settings
and command line that produced it.

------------------------------------------------------------------------
Color lookup tables, generated (bundled: .../Assets/LUTs/generated/**)
------------------------------------------------------------------------
The twelve ".cube" files under Assets/LUTs/generated/, AND the
Assets/LUTs/generate-luts.py script that writes them, were created for this
family by Jeremy Ellis and contributors, and are placed in the PUBLIC DOMAIN
under the Creative Commons CC0 1.0 Universal public domain dedication. No
rights are reserved and no attribution is required.

They are not derived from any third-party table. Each is defined by arithmetic
stated in the file's own comment header, in the script, and in
Assets/LUTs/MANIFEST.txt - a matrix, a curve, a per-channel scale - and is
computed from that arithmetic alone. The script needs only the Python 3
standard library; it imports, downloads and installs nothing.

------------------------------------------------------------------------
Fonts
------------------------------------------------------------------------
The Roboto family this application uses as its default text font, and the Noto
faces it registers as fallbacks, arrive inside their NuGet package. No font
file is bundled in this folder.

------------------------------------------------------------------------
User content (opened at run time)
------------------------------------------------------------------------
The application writes a baked ".cube" file wherever the person using it
chooses, and its scripted mode can be pointed at a ".cube" file of your own.
The rights to any such file remain with its owner; nothing of the kind is
redistributed as part of this repository.

No further third-party attribution notices apply to this sample.
