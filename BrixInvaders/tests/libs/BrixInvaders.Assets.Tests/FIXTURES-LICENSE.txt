FIXTURES USED BY BrixInvaders.Assets.Tests
==========================================

The tests read the game's own asset files from BrixInvaders/assets/kenney, copied beside the test
executable at build time (assets/kenney/...). Nothing is copied into this folder and nothing is extracted.

  kenney_space-shooter-remastered.zip
  kenney_space-shooter-extension.zip
  kenney_planets.zip
  kenney_sci-fi-sounds.zip
  kenney_digital-audio.zip
      Kenney asset packs by Kenney (www.kenney.nl), released under Creative Commons Zero (CC0 1.0
      Universal): http://creativecommons.org/publicdomain/zero/1.0/
      Each zip carries Kenney's own License.txt.

  Kenney_asset_bundle.png
      Kenney's own marketing image for the Kenney game assets bundle
      (https://kenney.itch.io/kenney-game-assets). It is not part of a CC0 pack; it is used with credit
      to Kenney, as the game's Kenney card.

Ships, sounds and planets by Kenney - kenney.nl - CC0.
