THIRD-PARTY NOTICES
===================

This file documents third-party content that is bundled with, or used at run
time by, the PolyHavenBrowser sample application, together with the licenses
under which that content is provided.

Third-party CODE dependencies are consumed as NuGet packages. Each package
carries its own license and third-party notices in its own repository/package
(the CodeBrix.* packages ship their own THIRD-PARTY-NOTICES.txt), so those are
not reproduced here.

------------------------------------------------------------------------
Poly Haven assets (downloaded at run time)
------------------------------------------------------------------------
This sample browses and downloads 3D models (and their textures) from
Poly Haven (https://polyhaven.com) at run time.

Poly Haven assets are released under the Creative Commons CC0 1.0 Universal
public-domain dedication (https://creativecommons.org/publicdomain/zero/1.0/);
no attribution is required, though Poly Haven appreciates a credit.

None of these assets are redistributed as part of this repository; they are
fetched on demand and cached locally.

------------------------------------------------------------------------
Android head  (src/PolyHavenBrowser.Android)
------------------------------------------------------------------------
The Android head contains no third-party files of its own. Its build brings
in, as NuGet packages, the following third-party code that ends up inside the
Android application package:

  - Material Components for Android and the AndroidX libraries (Google), in
    their .NET bindings (Xamarin.Google.Android.Material, Xamarin.AndroidX.*),
    licensed under the Apache License, Version 2.0. They arrive through the
    CodeBrix.Android package, which draws every control with them.

  - SkiaSharp and SkiaSharp.NativeAssets.Android (Microsoft / .NET
    Foundation), licensed under the MIT License, with the Skia library they
    bundle (Google, BSD 3-Clause License). They arrive through
    CodeBrix.Android.Graphics3DGL, which reads the 3D preview back through
    them, and the Rendering library uses SkiaSharp for the product shots.

Each of those packages carries its own license and notices, and the
CodeBrix.Android packages ship their own THIRD-PARTY-NOTICES.txt; they are
not reproduced here.
