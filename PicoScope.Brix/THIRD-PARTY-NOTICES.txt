------------------------------------------------------------------------
Pico Technology ps2000 driver  (NOT bundled; resolved at run time)
------------------------------------------------------------------------
The oscilloscope driver itself - ps2000.dll with picoipp.dll on Windows,
libps2000.so with libpicoipp.so on Linux - is Pico Technology's proprietary
software, supplied with the PicoSDK, with the PicoScope desktop application,
or by the libps2000 package in Pico's apt repository.

Pico's SDK terms permit the driver to be copied and distributed as long as
Pico Technology's copyright statements are not removed, but the driver is not
open-source software: it keeps a field-of-use restriction limiting it to use
with Pico products or with data collected using Pico products, and a
mission-critical-use exclusion.

No Pico driver binary is committed to this repository or bundled with this
application. The application locates whatever driver is installed on the
machine at run time and loads it from there, so nothing proprietary is
redistributed here and no driver version is pinned.

------------------------------------------------------------------------
Measurements (captured at run time)
------------------------------------------------------------------------
The application displays signals captured from an oscilloscope attached to
the user's own machine, or synthesised by its own simulated device. Nothing
captured is written to disk or redistributed as part of this repository.

No further third-party attribution notices apply to this sample. Nothing
third-party is vendored into this folder: no fonts, no images, no driver
binaries, no data files.
